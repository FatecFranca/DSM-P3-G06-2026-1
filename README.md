# Pixelate — Plataforma de Divulgação de Eventos

Plataforma web para descoberta, organização e participação em eventos do universo gamer.

---

## Introdução

Muitos eventos culturais ligados à comunidade gamer não recebem a visibilidade necessária para alcançar seu público — o que gera baixa participação, menor engajamento e dificulta o crescimento das comunidades.

A **Pixelate** surge como solução centralizada para esse problema, conectando organizadores e participantes por meio de uma interface simples e acessível.

---

## Funcionalidades

**Perfil do Usuário**
- Gerenciar dados pessoais
- Visualizar eventos inscritos
- Visualizar eventos criados

**Cadastro de Eventos**
- Criar eventos com data, horário, local e descrição
- Divulgar e organizar atividades para a comunidade

**Inscrição em Eventos**
- Inscrição rápida e prática em eventos disponíveis
- Acompanhamento dos eventos inscritos no perfil

---

## Linguagens Utilizadas

- **Front-end:** React.js, HTML, CSS, JavaScript
- **Back-end:** Node.js
- **Banco de dados:** MongoDB
